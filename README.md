# Pesquisa de Satisfação - TudoWeb

Programa desenvolvido em Python para realizar uma pesquisa de satisfação
com clientes da empresa TudoWeb.

O programa coleta:
- Nome do entrevistado;
- Idade;
- Opinião sobre o atendimento.

## Opções de atendimento

1. EXCELENTE
2. BOM
3. RUIM

## Funcionamento

O programa utiliza uma estrutura de repetição `for` para realizar a pesquisa
com 50 entrevistados.

Também utiliza estruturas de decisão `if`, `elif` e `else` para identificar
a opinião informada.

Ao final, são exibidas as quantidades de respostas:

- EXCELENTE
- RUIM

## Teste

Foi realizado um teste inicial com 10 entrevistados para verificar o
funcionamento do programa.

## Tecnologias utilizadas

- Python 
- GitHub
- Visual Studio Code
